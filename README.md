# SMB

ReaPack distribution for the [Simple Media Browser](https://dsgdnb.com/reaper-media-browser)

## Install

1. In REAPER: **Extensions → ReaPack → Import repositories…**
2. Paste this URL:

   ```
   https://raw.githubusercontent.com/sakhnovkrg/ReaperSMBReapack/main/index.xml
   ```

3. **Extensions → ReaPack → Browse packages…**, find **Simple Media Browser**, install it, then restart REAPER.

> Requires **ReaImGui** ("ReaImGui: ReaScript binding for Dear ImGui"), installed via ReaPack.
